# 영화 추천 시스템

20232873 김성주

C++로 구현한 CLI 기반 영화 추천 시스템입니다. 합성 데이터 생성, 영화/사용자/평점 관리,
협업 필터링·장르 기반 추천, 통계 기능을 제공합니다.

## 빌드 및 실행
```
make          # 빌드
make run      # 실행 (./main)
make valgrind # 메모리 누수 점검
make clean    # 빌드 산출물 정리
```

## 디렉터리 구조
- `include/` : 헤더 파일
- `src/`     : 소스 파일
- `data/`    : CSV 데이터(영화/사용자/평점) 및 생성 시드

## 주요 기능
- 영화 관리: 추가 / 제목 검색 / 정렬 조회
- 사용자 관리: 추가 / 목록
- 평점 관리: 추가 / 영화별 조회
- 추천: 유사 사용자 / 사용자별(협업 필터링) / 장르별
- 통계: 전체·평점순·평가수순·장르별·연도별·사용자별

실행 시 기존 데이터 파일이 있으면 불러오며, 새로 생성할지 선택할 수 있습니다.
