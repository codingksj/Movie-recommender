# Movie Recommender (영화 추천 시스템)

**20232873 김성주**

## 개요

C++17 기반 CLI 영화 추천 프로그램입니다. CSV 파일로 영화·사용자·평점 데이터를 관리하고, 협업 필터링 및 장르 기반 추천, 통계 조회 기능을 제공합니다.

### 주요 기능

| 메뉴 | 기능 |
|------|------|
| 영화 관리 | 추가, 제목 검색, 정렬 조회 |
| 사용자 관리 | 추가, 목록 조회 |
| 평점 관리 | 추가, 영화별 평점 조회 |
| 추천 서비스 | 유사 사용자, 사용자별 추천, 장르별 추천 |
| 통계 서비스 | 전체 통계, 순위, 장르/연도별 통계, 사용자 상세 |

### 데이터 파일

| 파일 | 설명 |
|------|------|
| `data/movies.csv` | 영화 정보 |
| `data/users.csv` | 사용자 정보 |
| `data/ratings.csv` | 평점 정보 |
| `data/generate_seed.csv` | 합성 데이터 생성용 단어 시드 |

## 실행 방법

### 요구 사항

- g++ (C++17 지원)
- make

### 빌드 및 실행

```bash
cd Movie-recommender
make
./main
```

### 시작 시 데이터 선택

프로그램 실행 후 **데이터 초기화** 화면이 표시됩니다. 파일 상태(O/X) 확인 후 메뉴를 선택합니다.

- **1 — 기존 데이터 불러오기**: CSV 3개가 모두 있을 때 로드
- **2 — 새 데이터 생성**: 단계별 메뉴로 진행
  1. 덮어쓰기 확인 (기존 파일 있을 때)
  2. 영화 / 사용자 / 평점 개수 설정 (Enter = 기본값)
  3. 생성 확인 → 실행 → 결과 표시
- **0 — 종료**

### 메인 메뉴

데이터 로드 후 메인 메뉴에서 기능을 선택합니다. **0(종료 및 저장)** 을 선택하면 변경 사항이 CSV에 저장됩니다.
